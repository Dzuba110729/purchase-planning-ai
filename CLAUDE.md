## Правила проекта

- **Цифры только из `facts.json`.** В README, сводке и сценарии видео — только цифры из итогового файла расчёта `facts.json`. Сценарий видео собирается из этого файла, а не пишется «по памяти».
- **Данные и ключи не в git.** CSV, `share/` и `.env` никогда не попадают в git (защита: `.gitignore`, pre-commit, gitleaks, автотест `tests/test_repo_guards.py`).
- **Ключи и токены не писать нигде**: ни в код, ни в тесты, ни в логи, ни в чат. В репозитории только имена переменных в `.env.example`, значения — в секретах GitHub и локальном `.env`.
- **ИИ не меняет цифры заказа.** Цифры считает Python (`data`, `forecast`, `planning`); тексты ИИ их только пересказывают, и каждое число проверяется.
- **Имена в коде английские** (переменные, функции, файлы, поля); русский — в текстах для людей и комментариях.
- **Не переделывать прошлые этапы без причины**; этап закрыт, когда зелёные все его проверки.

## Команды

- `uv sync` — установить зависимости (Python 3.12, версии фиксирует `uv.lock`).
- `uv run pytest` — все тесты; один файл: `uv run pytest tests/<файл>.py`.
- `uv run purchasing --help` — команда проекта.
- `uv run pre-commit install` — включить проверки перед коммитом (нужен установленный `gitleaks`).
