## Что должно заработать

Папка проекта становится рабочим Python-проектом: `uv run pytest` проходит, CSV и ключи не могут попасть в git (запрещают `.gitignore`, проверка перед коммитом, сканер gitleaks и автотест), а на каждый push GitHub сам запускает тесты. В `CLAUDE.md` записаны правила проекта, в том числе «цифры только из `facts.json`». Пользователь включает push protection в GitHub сам (ему подсказывают, куда нажать).

Выполняется в сессии 2 из 10. Этап закрыт, только когда зелёные все проверки ниже; красные — чиним; не получилось — пишем в `.autopilot/PROGRESS.md` что именно и останавливаемся.

## Критерии приёмки

Проверки этапа 1. Каркас и защита (раздел «Проверка каждого этапа», дословно):

- [ ] `uv run pytest` запускается и проходит (пустой тест-заглушка).
- [ ] Автотест: в git нет ни одного `.csv` (`git ls-files` не находит CSV).
- [ ] gitleaks (сканер секретов) не находит ключей в репозитории и истории.
- [ ] Pre-commit hook (проверка перед каждым коммитом) блокирует коммит CSV и `.env` — проверяем, попытавшись закоммитить тестовый CSV.
- [ ] GitHub Actions на push запускает тесты — первый прогон зелёный.
