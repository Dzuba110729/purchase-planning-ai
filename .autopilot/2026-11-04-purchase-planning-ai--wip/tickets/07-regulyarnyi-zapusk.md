## Что должно заработать

GitHub Actions пересчитывает всё сам: по расписанию в 04:30 UTC, при загрузке данных в закрытый репозиторий и по кнопке; обновляет страницу GitHub Pages и присылает в Telegram сводку (что заказать, где риск, что изменилось, ссылка). При сломанных данных запуск падает с понятной ошибкой, старый дашборд остаётся, приходит уведомление; при неверном ключе DeepSeek запуск зелёный с шаблонными текстами. Есть скилл Claude Code для ручного запуска. Пользователь сам создаёт бота и кладёт токен в секреты GitHub.

Выполняется в сессии 8 из 10. Этап закрыт, только когда зелёные все проверки ниже; красные — чиним; не получилось — пишем в `.autopilot/PROGRESS.md` что именно и останавливаемся.

## Замечания

Токен Telegram и ключи не запрашивай и не записывай. Если не успеваем, Telegram-бот режется раньше карточки товара, но не раньше регулярного запуска. Здесь нужны действия пользователя в GitHub (секреты, закрытый репозиторий данных, deploy key, Pages): покажи ему, куда нажать, и остановись до его подтверждения.

## Критерии приёмки

Проверки этапа 7. Регулярный запуск (раздел «Проверка каждого этапа», дословно):

- [ ] Ручной запуск кнопкой в GitHub → зелёный, дашборд обновился, Telegram пришёл.
- [ ] Загрузка изменённого CSV в закрытый репозиторий → пересчёт запустился сам, в сводке видно «что изменилось».
- [ ] Сломанный CSV → запуск падает с понятной ошибкой, приходит уведомление в Telegram, **старый дашборд остаётся на месте**.
- [ ] Неверный ключ DeepSeek → запуск зелёный, тексты шаблонные, в Telegram пометка «ИИ недоступен».
- [ ] Запуск по расписанию сработал сам хотя бы один раз.
- [ ] Логи Actions прочитаны: нет данных и секретов (логи открытого репозитория видны всем).

### ИБ-риски этого этапа (дословно)

| **Утечка ключей** (DeepSeek, Telegram, доступ к репозиторию данных). | Только секреты GitHub, в коде и чате ключей нет. gitleaks в pre-commit. Включаем GitHub push protection (блокировка push с ключом). |
| **Логи и артефакты Actions видны всем** в открытом репозитории. | Не печатаем данные и ответы ИИ в лог. Не загружаем сырые данные как артефакты. Публикуем только готовую страницу. |
| **Слишком широкий доступ к закрытому репозиторию данных.** | Deploy key (ключ доступа к одному репозиторию) только на чтение. Не личный токен на весь аккаунт. |
| **Подмена или взлом сборки** (чужой код в Actions). | Минимальные права в workflow (`permissions`), версии Actions закреплены по хешу, зависимости зафиксированы в `uv.lock`. Запуск только по расписанию, push в main и кнопкой владельца. Без запуска от чужих pull request. |
| **Текст ИИ ломает страницу** (вредный код в ответе). | Текст ИИ вставляется только как текст, с экранированием. Отдельный автотест (этап 6). То же для Telegram. |
| **Бот пишет не тем людям.** | Отправка только в заранее заданный `chat_id`. Бот ничего не принимает на вход. |
| **ИИ или сайт недоступен.** | Запасная цепочка: Pro → Flash → шаблон. При ошибке данных старый дашборд не затирается. |
