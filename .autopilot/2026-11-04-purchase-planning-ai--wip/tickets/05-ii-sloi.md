## Что должно заработать

DeepSeek пишет сводку, пояснения и пометки об аномалиях только по «паспорту фактов»; каждый ответ проверяется (схема, числа, даты, коды, запрещённые темы — деньги, вес, контейнеры, названия); при сбое работает запасная цепочка Pro → Flash → шаблон, дашборд собирается при любом исходе. Пользователь сам кладёт ключ DeepSeek в секреты GitHub; ключ не попадает ни в чат, ни в файлы, ни в логи.

Выполняется в сессии 6 из 10. Этап закрыт, только когда зелёные все проверки ниже; красные — чиним; не получилось — пишем в `.autopilot/PROGRESS.md` что именно и останавливаемся.

## Критерии приёмки

Проверки этапа 5. ИИ-слой (раздел «Проверка каждого этапа», дословно):

- [ ] Автотест (без интернета, с подменой ответа): API не ответил / ошибка / мусор → включается запасная цепочка, дашборд собирается.
- [ ] Автотест: в DeepSeek уходят только разрешённые поля (белый список), проверяем содержимое запроса.
- [ ] Автотест: каждое число в тексте ИИ есть во входных данных; лишнее число → текст отбрасывается, ставится шаблон.
- [ ] Автотест: ответ ИИ проверяется по схеме (нужные поля, нужные типы).
- [ ] Живая проверка: 20 товаров, тексты прочитаны, стоимость запуска записана.
- [ ] Живая проверка: ключ API нигде не выводится в лог.

### Из «Только реальные данные» — как это устроено (дословно)

1. **ИИ видит только «паспорт фактов».** Python собирает по каждому товару JSON с готовыми фактами: продажи, остаток, заказы в пути, прогноз, рекомендация, дата. Пустые поля записаны явно: `"вес": "нет данных"`. Больше ИИ ничего не получает.
2. **ИИ разрешено не знать.** В промпте прямо: «используй только факты из паспорта; если факта нет — напиши "в данных нет"; не угадывай». Ответ «не знаю» считается правильным, а не ошибкой.
3. **Ответ — строго по форме** (JSON: текст, список использованных фактов, флаг «данных не хватило»). Ответ не по форме отбрасывается.
4. **Код проверяет каждый ответ ИИ:**
5. **Не прошло проверку** → одна повторная попытка с указанием ошибки → снова не прошло → шаблонный текст, собранный из тех же фактов кодом.
7. **Низкая «температура»** (параметр, который делает ответы ИИ менее фантазийными) — 0,2.

### Проверки раздела «Только реальные данные» (добавлены в этап 5, дословно)

- [ ] Автотест: ИИ вернул текст с числом, которого нет в паспорте → текст отброшен, стоит шаблон.
- [ ] Автотест: ИИ упомянул рубли, вес или контейнеры → текст отброшен.
- [ ] Живая «провокация»: спрашиваем ИИ про бюджет закупки и вес контейнера → он отвечает «в данных нет».
- [ ] Живая проверка: на 20 товарах доля текстов, прошедших проверку, записана в отчёт (цель — не ниже 90%, иначе правим промпт).
